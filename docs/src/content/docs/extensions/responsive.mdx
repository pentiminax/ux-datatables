## When To Use

Use Responsive for mobile-heavy usage and columns that cannot all fit on one line.

## Minimal Example

```php
$dataTable->responsive();
```

## Advanced Example

```php
use Pentiminax\UX\DataTables\Model\Extensions\ResponsiveExtension;

$dataTable->addExtension(
    new ResponsiveExtension(
        auto: true,
        detailsTarget: 0,
        detailsType: 'inline',
        orthogonal: 'display',
    )
);
```

`detailsType` accepts `'inline'`, `'column'`, `'colvis'`, or `false` to disable the hidden-column
details control entirely. Pass `breakpoints` (a list of `['name' => string, 'width' => int]` pairs)
to override DataTables' built-in breakpoint list; omit it to keep the defaults.

## Frequent Pitfalls

- Not setting column priorities when too many columns compete for visibility.
- Combining with checkbox selection without validating first-column rendering.
