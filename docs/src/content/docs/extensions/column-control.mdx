# Column Control Extension

## When To Use

Use Column Control when users need direct per-column order and filter controls in the table UI.

## Minimal Example

```php
$dataTable->columnControl();
```

## Behavior

The bundled `ColumnControlExtension` serializes default controls for:

- ordering actions (asc, desc, add/remove order)
- per-column search input with `Contains`, `Starts`, `Ends`, `NotContains`,
  `Equal`, `NotEqual`, `Greater`, `GreaterOrEqual`, `Less`, `LessOrEqual`,
  `Empty`, and `NotEmpty` logics

### Search case sensitivity and PostgreSQL compatibility

The LIKE-based logics (`Contains`, `Starts`, `Ends`, `NotContains`) are
**case-insensitive** and routed through the `UX_DATATABLES_SEARCH` DQL function.
This function applies `LOWER()` to the field and, on PostgreSQL, wraps it in
`CAST(… AS TEXT)` before the LIKE comparison. The cast resolves the
`operator does not exist: uuid ~~ text` error that occurs when a column is
mapped with Doctrine type `uuid` or `guid`.

No configuration is required. The function is registered automatically.

## Frequent Pitfalls

- Expecting custom control layouts from the default extension payload.
- Enabling it without ensuring the target columns are searchable/orderable.
