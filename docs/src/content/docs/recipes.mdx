Short, end-to-end recipes for the setups teams reach for most often. Each recipe assumes you
already completed [Installation](/getting-started/installation/).

| Recipe                                                      | When to use it                                            |
| ----------------------------------------------------------- | --------------------------------------------------------- |
| [Client-side inline data](/recipes/client-side-inline/)     | Small datasets already in the controller                  |
| [Doctrine server-side](/recipes/doctrine-server-side/)      | Large entity tables with paging and search on the backend |
| [Filters](/recipes/filters/)                                | Declarative filter popover on a server-side table         |
| [Actions with CSRF and voter](/recipes/actions-csrf-voter/) | Edit/delete buttons with secure mutation endpoints        |
| [MoneyColumn](/recipes/money-column/)                       | Currency amounts stored as cents                          |
| [Mercure live updates](/recipes/mercure-live-update/)       | Auto-refresh when data changes elsewhere                  |
