Short, end-to-end recipes for the setups teams reach for most often. Each recipe assumes you
already completed [Installation](/ux-datatables/getting-started/installation/).

| Recipe | When to use it |
| --- | --- |
| [Client-side inline data](/ux-datatables/recipes/client-side-inline/) | Small datasets already in the controller |
| [Doctrine server-side](/ux-datatables/recipes/doctrine-server-side/) | Large entity tables with paging and search on the backend |
| [Filters](/ux-datatables/recipes/filters/) | Declarative filter popover on a server-side table |
| [Actions with CSRF and voter](/ux-datatables/recipes/actions-csrf-voter/) | Edit/delete buttons with secure mutation endpoints |
| [MoneyColumn](/ux-datatables/recipes/money-column/) | Currency amounts stored as cents |
| [Mercure live updates](/ux-datatables/recipes/mercure-live-update/) | Auto-refresh when data changes elsewhere |
