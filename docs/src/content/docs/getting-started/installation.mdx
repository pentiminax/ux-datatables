## Requirements

- PHP **8.2+**
- Symfony **7.x** or **8.x**
- [Symfony UX StimulusBundle](https://symfony.com/bundles/StimulusBundle/current/index.html) **2.x** or **3.x**

## Install the Bundle

<Steps>
**Install via Composer**

    ```bash
    composer require pentiminax/ux-datatables
    ```

    Symfony Flex will automatically enable the bundle.

**Install Assets**

    <Tabs>
      <TabItem label="AssetMapper">
        If you're using **AssetMapper** (recommended for Symfony 7+), the next step installs the packages you need.
      </TabItem>
      <TabItem label="Webpack Encore">
        If you're using **Webpack Encore**, install the JavaScript dependencies and rebuild your assets:

        ```bash
        npm install --force
        npm run watch
        ```
      </TabItem>
    </Tabs>

**Set up the frontend**

    ```bash
    php bin/console ux-datatables:install --style=tailwind buttons responsive select
    ```

    The command copies the package loaders for your kit (`tailwind`, `dt` or `bs5`) and extensions
    into `assets/datatables.js`, enables the `datatable` controller, sets `style_framework`, and runs
    `importmap:require` (AssetMapper) or prints the `npm install` line (bundlers). See
    [Frontend packages](/guide/package-loading/).

**Verify Installation**

    The `@pentiminax/ux-datatables/datatable` Stimulus controller is enabled in
    `assets/controllers.json` and your loaders are imported from `assets/stimulus_bootstrap.js`.

</Steps>

## Bundle Configuration

Create a configuration file at `config/packages/data_tables.yaml`:

```yaml
data_tables:
  options:
    language: en-GB
    layout:
      topStart: pageLength
      topEnd: search
      bottomStart: info
      bottomEnd: paging
    lengthMenu: [10, 25, 50]
    pageLength: 10
  style_framework: dt
  table_attributes:
    class: 'table'
  extensions:
    buttons: [csv, excel, pdf, print]
    select:
      style: single
```

## Styling

The bundle ships with the DataTables default theme enabled. Check your `assets/controllers.json`:

```json
{
  "controllers": {
    "@pentiminax/ux-datatables": {
      "datatable": {
        "enabled": true,
        "autoimport": {
          "datatables.net-dt/css/dataTables.dataTables.min.css": true,
          "datatables.net-bs5/css/dataTables.bootstrap5.min.css": false
        }
      }
    }
  }
}
```

The bundle supports Bootstrap 5 and the default DataTables theme (which the Tailwind theme builds on). Declare yours with `style_framework`; Bootstrap 3 and 4 are not supported.

See [Styling](/guide/styling/) for the full setup guide.

<Aside type="danger" title="Secure the Ajax routes before production">
  The Symfony Flex recipe imports the `/datatables/ajax/*` routes in
  `config/routes/data_tables.yaml`; without Flex, import
  `@PentiminaxDataTablesBundle/config/routes.php` yourself. The table token they use identifies
  **which** table is requested, not **who** is requesting it, so it is not a substitute for
  authentication. Protect these routes with your application's `security.access_control` to match
  the pages that render your tables. See [Securing Ajax Routes](/getting-started/security/).
</Aside>
