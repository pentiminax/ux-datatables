## What / When

Use `MoneyColumn` when cells are monetary amounts. Prefer it over `NumberColumn` plus custom JS.

## Minimal Example

```php
use Pentiminax\UX\DataTables\Column\MoneyColumn;
use Pentiminax\UX\DataTables\Column\TextColumn;

public function configureColumns(): iterable
{
    yield TextColumn::new('name', 'Product');
    yield MoneyColumn::new('price', 'Price')
        ->setField('priceInCents') // e.g. 1999 → €19.99
        ->currency('EUR')
        ->storedAsCents();
}
```

## Pitfalls

<Aside type="note">
  Keep integers (or floats) as the column value. Display formatting runs in the browser so numeric
  sorting stays correct.
</Aside>
